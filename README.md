# 지역사회보장계획 작성지원 플랫폼

## ▶ 바로 쓰기 — **https://beaver21c.github.io/rssp_help/**

제6기(2027~2030) **시·군·구** 지역사회보장계획을 장·절 단위로 작성해 한글 문서(.hwpx)로
산출하는 도구. 설치 없이 브라우저에서 돌고, 계획서 원고·첨부파일·API 키는 기기 밖으로
나가지 않는다(Gemini 호출만 예외).

크롬·엣지 권장(작업 폴더 기능이 크로미움 계열 전용). 키가 없어도 **지역여건 분석**·
**양식 점검**·**양식만 넣기**는 그대로 쓸 수 있다.

## 세 가지 기능

| | 무엇 | 어떻게 |
|---|---|---|
| ① | **AI로 절 쓰기** | 절을 고르면 「수립 안내」의 해당 절 작성 지침·표 양식·작성례가 자동으로 붙는다. 요청·참고 원문·첨부파일을 넣어 초안을 만들고, 검사를 통과하면 그 절만 hwpx로 낸다 |
| ② | **지표로 지역여건 분석** | 시·군·구를 고르면 「지역사회보장지표」 핵심 22개를 비교집단과 대조해 그래프를 그리고, 그림이 박힌 절 hwpx를 낸다 |
| ③ | **양식 점검·수정** | 이미 쓴 hwpx를 올리면 마커 원고로 되돌려 계층·기호·표 양식·수량 제약을 검사하고, 안내서 서식을 다시 입혀 낸다 |

합본은 만들지 않는다. 장·절 단위로 내고 한글에서 이어 붙인다.

## 서식이 어떻게 지켜지는가

산출물은 **안내서 원본을 템플릿으로 두고 본문 구역(`Contents/section2.xml`)의 문단만
갈아 끼우는** 방식으로 만든다. `header.xml`을 한 바이트도 건드리지 않으므로 글꼴·한글
자동 번호매기기·자동 글머리표·쪽 설정이 원본 그대로 남는다. 표지·제출문·심의결과서·
발간사도 그대로 유지된다.

서식을 JSON으로 베껴 새 문서를 짓는 방식(프로파일 방식)은 쓰지 않는다. 안내서가 한글의
`hh:heading` 자동 번호매기기를 쓰고 있어 그 방식으로는 번호가 사라지기 때문이다.

**전략체계도**(27×29·16×15)는 칸을 잘게 나눠 병합하고 칸마다 테두리를 달리 준 표라 글로
받아쓸 수 없다. 그래서 안내서의 그 문단을 통째로 떼어 두었다가(`app/data/layout/*.xml`)
산출할 때 그대로 끼워 넣는다. `header.xml`이 같으므로 병합·테두리·글꼴이 원본 그대로
살아나고, 담당자는 한글에서 칸의 글자만 고치면 된다.

## 여는 법

빌드 과정이 없다. `app/`을 정적으로 서빙하면 그대로 돈다.

```bash
python3 -m http.server 8000 --directory app     # http://localhost:8000
```

GitHub Pages로 배포하려면 저장소 Settings → Pages → Source를 **GitHub Actions**로 두면
`.github/workflows/pages.yml`이 `app/`을 올린다.

## Gemini API 키

기능 ①과 문장 다듬기에만 쓴다. 키가 없어도 **②와 ③은 그대로 동작**한다.

키는 **화면 맨 위 설정 띠**에서 사용자가 직접 넣는다. 들어오면 이 띠가 가장 먼저 보이고,
확인이 끝나야 AI 단추가 열린다.

- 키는 브라우저 저장소에만 둔다. 기본은 세션 저장(탭을 닫으면 삭제), 선택하면 이 브라우저에 유지
- 요청은 `x-goog-api-key` 헤더로만 보낸다. 주소창·리퍼러·프록시 기록에 남지 않는다
- 확인은 **모델 목록 조회 + 실제 생성 1회**다. 목록만 보면 「목록은 되는데 생성만 막힌 키」와
  「우리가 아는 모델 이름이 하나도 안 남은 상황」이 걸러지지 않는다

### 어떤 모델을 쓰는가 — 이름이 아니라 계열

기본은 **Flash-Lite 계열 중 살아 있는 가장 높은 판**이다. 판 번호를 코드에 박지 않는다.

- 무료 등급에서 **하루 요청 수(RPD)가 가장 넉넉한 계열**이라 기본으로 삼는다
- 판을 박아 두면 구글이 올릴 때마다 도구가 멈춘다. 2026-09-08에 실제로 겪었다 —
  `gemini-2.5-flash-lite`를 지정했더니 *"no longer available to new users. Please update your
  code to use models/gemini-3.5-flash-lite"* 가 돌아왔다
- 그래서 계열(`flash-lite`)만 정하고 판은 **실행 시점 목록에서 가장 높은 것**을 고른다
- 다른 모델을 쓰려면 화면의 [우선 모델]에서 직접 고른다

### 모델이 바뀌어 멈추는 위험에 대한 설계

| 겹 | 하는 일 |
|---|---|
| ① 실행 시점 조회 | 이름을 박지 않는다. 그때그때 목록을 받아 flash → 높은 판 → lite 차례로 세운다 |
| ② 성공한 이름 기억 | 마지막에 응답한 모델을 다음번 맨 앞에 세운다. 404면 즉시 버린다 |
| ③ 목록 창구가 막혀도 진행 | 목록 조회가 실패해도 내장 이름으로 밀어붙이고, 「목록을 못 받았다」는 화면에 남긴다 |
| ④ 내려간 모델은 갈아탄다 | *"no longer available … use models/X"* 를 만나면 **구글이 지목한 X를 그 자리에서 이어 붙여** 시도하고, 기억해 둔 묵은 이름은 지운다 |
| ⑤ 사람이 고르기 | [우선 모델]에서 직접 고르고, 그것이 죽으면 [자동 모델로 되돌려 다시 확인]으로 빠져나온다 |

분당 한도(429)는 2초 쉬었다 다음 모델, 지원 중단(404)은 즉시 다음 모델, 키 오류는 즉시 중단한다.
확인이 통하지 않아도 [확인 실패해도 그냥 쓰기]로 진행할 수 있다(막다른 길을 만들지 않는다).

### 무료 등급 하루 몫 — 얼마나 쓰고 언제 되돌아오는가

무료 등급은 **하루 요청 수(RPD)** 가 정해져 있고 그 몫은 **태평양 자정**에 되돌아온다
(한국시간으로 여름 오후 4시·겨울 오후 5시. 화면은 서머타임을 계산해 실제 시각으로 적는다).

| 계열 | 하루 요청 수(참고값) | 분당 | 분당 토큰 |
|---|---|---|---|
| Flash-Lite | 1,000 | 15 | 250,000 |
| Flash | 250 | 10 | 250,000 |
| Pro | 100 | 5 | 250,000 |

> **이 숫자는 참고값이다.** 출처는 구글 [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)
> 문서이나 이 저장소 작업 환경에서 원문을 직접 열지 못해(망 정책) 검색 결과로 확인한 값이며,
> 구글 공지·계정 등급에 따라 바뀐다. **도구는 이 숫자로 막지 않는다** — 실제 차단은 구글이 돌려준
> 429로 판정하고, 응답에 `limit:` 값이 적혀 오면 그 관측값을 대신 쓴다.

몫을 아끼고 스스로 멈추는 장치(`app/assets/quota.js`)

- **오늘 쓴 횟수**를 태평양 날짜 기준으로 세어 띠에 표시한다(성공한 호출만 센다)
- **페이지를 열 때마다 확인 호출을 하지 않는다.** 오늘 이미 확인한 키면 실호출을 건너뛴다
  ([다시 확인]을 누르면 그때는 진짜로 부른다)
- **한 모델의 하루 몫이 끝나면** 장부에 적고 그날은 다시 두들기지 않는다. 남은 모델로 먼저 넘어간다
- **전부 떨어지면 그 자리에서 멈춘다.** 작업 도중이라도 붙잡지 않고 되돌아오는 시각을 알리며,
  AI 단추만 잠기고 지역여건 분석·양식 점검·[양식만 넣기]는 그대로 쓸 수 있다

위 다섯 겹과 몫 장부는 `tests/test_quota.mjs`·`tests/test_gemini.mjs`(가짜 fetch)와
`tests/test_e2e.mjs`(브라우저에서 구글 창구를 가로채 이름 교체·목록 창구 사망·키 거부·
하루 몫 소진·내려간 모델 갈아타기를 실제로 만들어 본다)에서 검사한다.

### 계정 쪽 문제는 기다려도 안 풀린다

**선불 크레딧 소진**(`Your prepayment credits are depleted`)은 계정 단위라 모델을 바꾸거나
기다려도 똑같이 막힌다. 그래서 이 사유를 만나면 목록을 더 돌지 않고 곧바로 멈추고,
화면에 「기다려도 풀리지 않는다」와 함께 AI Studio 결제 화면으로 가는 길을 준다.

모델별 일일 한도(`You exceeded your current quota, please check your plan and billing
details`)는 다른 모델로 넘어가면 통할 때가 있으므로 여기 걸리지 않는다 —
'billing'이라는 낱말이 아니라 크레딧 소진 문구만 집는다.

## 작업 폴더 — 앞서 쓴 절을 맥락으로 삼기

절을 하나씩 내다 보면 **앞 절이 뒤 절을 구속한다.** 제1절에서 정한 추진전략 이름이 제3절
세부사업에 그대로 이어져야 하고, [전략 2~4]는 전략 1의 구조를 되풀이하며, 「추진전략 5개
이내」 같은 수량 제약은 앞에서 정한 개수를 뒤에서 지켜야 한다. 지금까지는 담당자가 그것을
매번 손으로 붙여넣어야 했다.

**작업 폴더**를 지정하면 산출물이 그 폴더에 바로 쌓이고, 앞 절의 결정 사항이 자동으로 따라간다.

| 단계 | 하는 일 |
|---|---|
| ① 폴더 지정 | `showDirectoryPicker`로 폴더를 고른다. 핸들을 IndexedDB에 담아 다시 들어와도 이어 쓴다(권한만 한 번 다시 묻는다) |
| ② 폴더로 저장 | 절·지역여건·재조판 산출물이 내려받기 대신 그 폴더로 간다. 폴더에 못 쓰면 내려받기로 물러난다 |
| ③ 앞 절 되돌리기 | 폴더의 hwpx를 눌러 마커 원고로 되돌려 [참고 원문]에 넣는다(사람이 고르는 길) |
| ④ 맥락 카드 | 절을 낼 때마다 **결정 사항만** 뽑아 폴더의 `_맥락.json`에 쌓는다 |
| ⑤ 자동 주입 | 다음 절 지시문에 관련 있는 카드만 골라 넣는다 |

### 왜 전문이 아니라 카드인가

마디가 65개다. 앞 절 전문을 매번 실어 보내면 뒤로 갈수록 요청이 선형으로 커져 무료 등급의
분당 토큰 한도에 먼저 걸리고, 관계없는 문장이 섞여 원고 품질도 떨어진다.

- 카드에 담는 것 — **비전·전략 이름·사업명·표 골격(머리행+첫 칸)·핵심 수치**
- 표 주(※)·도식 자리표·열 너비 지정은 담지 않는다
- 뽑는 데 **AI를 부르지 않는다**(규칙 기반). 하루 몫을 축내지 않는다
- 카드 하나는 **700자 상한**, 지시문에 들어가는 맥락 글 전체는 **6,000자 상한**
- 상한에 걸리면 덜어 내는 차례 — 수치 → 요지 → 표 → **이름은 끝까지 지킨다**(뒤 절을 가장 세게 구속한다)

시험에서 65개 마디를 차례로 쌓아 보면 맥락 글은 최대 5,539자에 머문다. 같은 원고를 전문으로
날랐다면 207,155자였다(**37분의 1**).

### 어느 카드를 넣는가

안내서의 실제 절 관계에서 나온 규칙이다.

| 규칙 | 가중치 | 까닭 |
|---|---|---|
| 준용 원본(`mirrors`) | +100 | [전략 2~4]는 전략 1의 구조를 되풀이한다. 이름이 흔들리면 문서가 깨진다 |
| 제1절 카드 | +60 | 뒤의 모든 절이 여기서 정한 목표·전략에 매달린다 |
| 같은 장 | +40 | 한 장 안에서 용어가 갈리면 곧바로 눈에 띈다 |
| 바로 앞 절 | +30 | 흐름이 이어져야 한다 |
| 차례상 가까움 | +최대 20 | 멀수록 덜 매인다 |

아직 쓰지 않은 뒤쪽 절은 0점이라 들어가지 않는다.

### 제약

- **크롬·엣지 계열에서만** 폴더 지정이 된다. 파이어폭스·사파리에서는 종전대로 내려받기로
  가고, 맥락 카드는 그 탭에서만 유지된다(화면이 그 사실을 적는다)
- 보안 컨텍스트(https 또는 localhost)여야 한다. GitHub Pages는 https라 문제없다
- 폴더 고르기는 **사용자가 눌러야** 뜬다(브라우저 규칙). 자동으로 열 수 없다
- 앞 절 초안의 오류가 뒤로 옮아갈 수 있다. AI가 쓴 문장은 초안이며 담당자 확인이 전제다

## 첨부파일

| 형식 | 처리 |
|---|---|
| `hwpx` `xlsx` `pptx` `csv` `txt` `md` `html` | **브라우저 안에서** 텍스트·표를 뽑는다. 파일이 밖으로 나가지 않는다 |
| `pdf` `png` `jpg` | 파싱하지 않고 **원본을 Gemini로 보낸다**. 미공개 자료는 올리기 전에 확인할 것 |
| `hwp` | 읽지 못한다. 한글에서 [다른 이름으로 저장] → HWPX 문서로 저장할 것 |

외부 라이브러리를 쓰지 않는다. xlsx·pptx는 OOXML(zip+XML)을 직접 뜯어 읽는다.

## 시험

```bash
python3 tests/test_catalog.py        # 카탈로그 추출 결과·템플릿 무결성
node tests/test_form_parity.mjs      # 양식 보존 빌더가 파이썬판과 같은 XML을 내는가
node tests/test_docread.mjs          # 되돌리기 — 본문 구역만·마커 왕복       (27건)
node tests/test_attach.mjs           # 첨부파일 추출                         (139건)
node tests/test_indicator.mjs        # 지표 산출·비교집단·차트                (59건)
node tests/test_catalog_js.mjs       # 절 카탈로그 소비 모듈                  (79건)
node tests/test_quota.mjs            # 무료 몫 장부·태평양 리셋·서머타임         (55건)
node tests/test_context.mjs          # 맥락 카드 뽑기·고르기·예산               (59건)
node tests/test_gemini.mjs           # 키·모델 폴백·실호출 확인·몫 소진(가짜 fetch)(192건)
node tests/test_e2e.mjs              # 브라우저에서 65개 마디 전부 산출        (766건)
```

`test_e2e.mjs`는 Chromium을 띄워 실제 화면을 조작한다. 마디마다 양식을 넣고 hwpx를
받아 열어 보며 ①표지·제출문·글꼴이 원본과 해시가 같은지 ②안내서가 정한 표가 다
들어갔는지 ③열 수와 머리행이 그대로인지 ④전략체계도가 칸 병합·테두리째 들어갔는지를
확인한다. 마지막에 구글 창구를 가로채 API 키 확인 절차(키 입력 → 실호출 확인 → 모델
교체 → 목록 창구 사망 → 키 거부 → 하루 몫 소진 → 내려간 모델 갈아타기 → 키 삭제)를 돌려 보고,
가짜 폴더를 끼워 작업 폴더 저장·목록·되돌리기·카드 누적·지시문 주입까지 확인한다. `--max=3`으로 줄여 돌릴 수 있고
`--only=02-나-1`로 한 마디만 볼 수도 있다.

최근 실행 결과 — 65/65 마디 산출, 단언 766건 전부 통과.

## 산출 방식에 관한 주의

- 지표의 모든 "평균"은 시·군·구 **단순평균**(unweighted)이며 시·도 공식 소계와 산출 방식이 다르다
- 예산 관련 데이터의 시·도 행은 본청값이라 화면에서는 시·군·구 값만 쓴다
- 지표마다 생산 주기가 달라(2025·2024 혼재) 연도를 고정하지 않고 **지표별 최신값**을 쓰고 연도를 병기한다
- 대구광역시 군위군은 시·군·구 7대 유형이 부여돼 있지 않아 유형별 비교에서 빠진다(광역·전국 비교는 정상)
- 아직 못 붙인 것들은 `docs/BACKLOG.md`에 사유와 함께 적어 두었다
- AI가 쓴 문장은 초안이다. 통계·법조문·사업명은 반드시 담당자가 확인한다
